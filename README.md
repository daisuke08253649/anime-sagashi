# アニメさがし — プロトタイプ

Next.js App Router / React / TypeScript / Tailwind CSS、shadcn方式のButton（Radix Slot・CVA）を使った日本語のアニメ発見サイトです。

## 実装済みのソース

- ホーム `/`、検索 `/search/`、作品詳細 `/anime/anime-1/` 〜 `/anime/anime-50/`
- 50作品の編集済み仮データ、作品名・英語名・別名検索
- ジャンル、気分、TV/映画の組み合わせ検索、人気・話題・年による並び替え
- ジャンルと気分の一致度に基づく類似作品と推薦理由
- URLクエリーによる検索状態の共有・再読み込み復元
- 架空の口コミとネタバレ開閉、最新情報の未連携表示
- スマホ向けレイアウト、キーボード操作、404、検索結果なし、画像読み込み失敗時の文字カバー

## 起動

ネットワークからnpmのパッケージを取得できる環境で、次を実行してください。

```sh
npm install
npm run dev
```

開発画面: http://127.0.0.1:3000

```sh
npm run typecheck
npm test
npx playwright install chromium
npx playwright test
npm run build
```

初期版は `output: 'export'` の静的出力です。実データ連携時はサーバー実行を有効にし、サーバー側だけでAPIキーを扱います。DB取得への差し替えは `lib/catalog.ts` のデータ取得境界から進めます。

## データと画像

タイトルと年は編集した仮カタログです。順位・口コミ・ニュースは実際のXや公式発表から取得したものではありません。各画面でサンプルと明記しています。8作品の画像は検索で確認できた外部掲載先を参照し、作品詳細に掲載元を表示しています。画像の配信可否と公開利用条件は未確認です。その他は意図的な文字カバーです。一般公開前に利用可能な画像提供元へ統一してください。
